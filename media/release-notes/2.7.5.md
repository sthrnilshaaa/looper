## What's New

### New
- Windows support: installer and portable zip
- First-run setup screen on Linux and Windows
- Songs tagged with several artists (A / B, feat. C) now show under each artist
- Optional "Group by album" on artist pages (Settings)
- Haptic strength setting (Low / Medium / High)
- "Group Continued Lines" lyrics setting

### Improved
- Bouncier, smoother player motion: catch mid-flight, throw either way, drag the mini bar down to dismiss
- Springy classic music bar and smoother artwork handoff
- Rubber-band scrolling, list and dialog animations
- Faster startup: Home and Songs load in parts instead of waiting for the whole library
- Better 120 Hz performance and lower memory use
- Richer colours taken from artwork
- Music breaks in lyrics open up only when they start

### Fixed
- Playlist duration display
- Artwork corners snapping when the player closes
- Playing indicator flicker on the mini bar
